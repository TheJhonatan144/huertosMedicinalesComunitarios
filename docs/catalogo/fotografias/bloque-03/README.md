# Fotografías referenciales del bloque 03

Nueve fotografías de Wikimedia Commons, guardadas localmente. Su identificación corresponde a la ficha del archivo y su categoría taxonómica; no identifica ejemplares de las comunidades del proyecto. Las fotografías no son evidencia de presencia en las provincias del catálogo.

No se retocaron las fotografías. Se conservan miniaturas suministradas por Wikimedia. El archivo fotografias.json conserva procedencia, dimensiones, hash SHA-256 y créditos que se guardan en la ficha.
